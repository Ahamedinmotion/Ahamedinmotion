# Visual assets

The profile uses custom SVG artwork based on the supplied 42 Abu Dhabi visual
language. Headlines use VG5000, designed by Justin Bihan and distributed by
Velvetyne under the SIL Open Font License. Text is rendered as filled glyph
paths so the artwork does not depend on installed fonts or external font servers.

The generative map-like pattern is original decorative geometry, not a literal
map. Project diagrams are illustrative; no waveform or neural network artwork
should be read as measured results. No institutional endorsement is implied.

The six `*-motion.svg` files are generated by `tools/build_motion.py`.
The unmodified VG5000 font is bundled in `tools/fonts/` with its SIL Open Font
License. The font identifies Velvetyne Type Foundry and designer Justin Bihan.
Static companion graphics remain available for the still edition. Motion is illustrative
and does not represent live system status, actual signal samples, or individual
attainment of curriculum ranks.
